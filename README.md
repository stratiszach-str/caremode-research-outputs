# CAREMODE Research Outputs

This repository gathers scientific works funded by the CAREMODE project that have already been published in international journals and conferences.

## CAREMODE Project

**CAREMODE – Improvement of the Biomedical Research of the SSN (PNRR M6C2.2.1)**

---

## Research Topics

The publications included in this repository cover research areas including:

- Embedded Systems
- FPGA Acceleration
- Hardware/Software Co-Design
- Approximate Computing
- Approximate Arithmetic Circuits
- Matrix Multiplication Accelerators
- VLSI Design
- FinFET Technologies
- Artificial Intelligence Hardware
- Edge AI Acceleration
- Biomedical Signal Processing
- Forcecardiography (FCG)
- Real-Time Processing Systems
- Wireless Biomedical Monitoring
- Telemedicine Technologies
- Neural Networks Hardware Acceleration
- Spike Detection and Classification
- Low-Power Integrated Circuits
- Error-Tolerant Computing
- Digital Signal Processing
